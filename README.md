# Тестовое задание: Программист 1С

## Описание задачи

Разработать конфигурацию с нуля для учета приобретения и реализации товаров.

[Подробное ТЗ →](./Tt.md)

---

## Реализованный функционал

| Компонент | Описание |
|-----------|----------|
| **Документ «Приобретение товаров»** | Поступление товара на склад |
| **Документ «Реализация»** | Продажа товара со склада |
| **Регистр «Складские остатки»** | Хранит текущие остатки |
| **Регистр «Выручка по продажам»** | Хранит данные о продажах и себестоимости |
| **Отчет по остаткам** | Показывает текущие остатки |
| **Отчет по продажам с наценкой** | Показывает продажи и рассчитанную наценку |
| **Списание по средней** | Себестоимость рассчитывается как средняя по всем поступлениям |

---

## Структура конфигурации

### Справочники

| Название | Назначение |
|----------|------------|
| **Номенклатура** | Список товаров |
| **Склады** | Список складов |
| **Контрагенты** | Список поставщиков и покупателей |

### Документы

| Название | Движения |
|----------|----------|
| **Приобретение товаров** | `Складские остатки` (Приход) |
| **Реализация** | `Складские остатки` (Расход), `Выручка по продажам` (Обороты) |

### Регистры накопления

| Название | Тип | Измерения | Ресурсы |
|----------|-----|-----------|---------|
| **Складские остатки** | Остатки | Склад, Номенклатура | Количество, Сумма |
| **Выручка по продажам** | Обороты | Номенклатура, Покупатель | Количество, СуммаПродажи, Себестоимость |

---

## Логика расчета средней себестоимости

При проведении документа **«Реализация»**:
1. Запрашивается текущий остаток товара на складе (количество и сумма).
2. Рассчитывается средняя себестоимость единицы:  
   `Средняя = Сумма остатка / Количество остатка`
3. Себестоимость списания:  
   `Сумма списания = Средняя × Количество продажи`
4. В регистр **«Складские остатки»** записывается **Расход** с этой суммой.
5. В регистр **«Выручка по продажам»** записывается **Приход** с суммой продажи и себестоимостью.

## Как развернуть

1. Установить платформу **1С:Предприятие** (учебная версия). Скачать бесплатную **учебную версию** (версия платформы **8.3.27.1508**) на официальном сайте:
- Ссылка: https://online.1c.ru/catalog/programs/program/28766016/
2. Создать информационную базу.
3. Загрузить конфигурацию из файла `1Cv8.cf`.
4. Запустить в режиме **1С:Предприятие**.
