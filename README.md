# Тестовое задание: Программист 1С

##  Описание задачи

Разработать конфигурацию с нуля для учета приобретения и реализации товаров.

[ТЗ подробнее](/Тестовое_задание.md)

**Функционал:**
- Документ "Приобретение товаров"
- Документ "Реализация товаров"
- Отчет по складским остаткам
- Отчет по продажам с наценкой
- Расчет себестоимости по средней

---

##  Решение

Подробности в [REPORT.md](/REPORT.md)


### Справочники

| Название | Назначение |
|----------|------------|
| **Товары** | Хранит информацию о номенклатуре |
| **Склады** | Хранит информацию о складах |

### Документы

| Название | Назначение | Движения |
|----------|------------|----------|
| **ПриобретениеТоваров** | Фиксирует поступление товара на склад | `СкладскиеОстатки` (Приход) |
| **РеализацияТоваров** | Фиксирует продажу товара | `СкладскиеОстатки` (Расход), `ВыручкаПоПродажам` (Обороты) |

### Регистры накопления

| Название | Тип | Измерения | Ресурсы |
|----------|-----|-----------|---------|
| **СкладскиеОстатки** | Остатки | Товар, Склад | Количество, Сумма |
| **ВыручкаПоПродажам** | Обороты | Товар | СуммаПродажи, Себестоимость |

### Отчеты

| Название | Источник данных | Назначение |
|----------|-----------------|------------|
| **Отчет по складским остаткам** | `СкладскиеОстатки.Остатки` | Показывает текущие остатки товаров на складах |
| **Отчет по продажам с наценкой** | `ВыручкаПоПродажам.Обороты` | Показывает продажи и рассчитанную наценку |

##  Логика расчета средней себестоимости

При проведении документа `РеализацияТоваров`:

1. Для каждой строки табличной части выполняется запрос к регистру `СкладскиеОстатки` на момент времени документа.
2. Вычисляется средняя цена: `СредняяЦена = ОстатокСумма / ОстатокКоличество`.
3. Полученная средняя цена записывается как себестоимость в регистр `ВыручкаПоПродажам`.

**Фрагмент кода:**
```bsl
// Получение средней себестоимости
Запрос = Новый Запрос;
Запрос.Текст = 
"ВЫБРАТЬ
|   СкладскиеОстаткиОстатки.КоличествоОстаток КАК Количество,
|   СкладскиеОстаткиОстатки.СуммаОстаток КАК Сумма
|ИЗ
|   РегистрНакопления.СкладскиеОстатки.Остатки(&МоментВремени, Товар = &Товар И Склад = &Склад) КАК СкладскиеОстаткиОстатки";

Запрос.УстановитьПараметр("МоментВремени", МоментВремени());
Запрос.УстановитьПараметр("Товар", СтрокаТЧ.Товар);
Запрос.УстановитьПараметр("Склад", Склад);

Результат = Запрос.Выполнить();
Если Результат.Пустой() Тогда
    СредняяЦена = 0;
Иначе
    Выборка = Результат.Выбрать();
    Выборка.Следующий();
    СредняяЦена = Выборка.Сумма / ?(Выборка.Количество <> 0, Выборка.Количество, 1);
КонецЕсли;
